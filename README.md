# My Zakat Tool

WordPress plugin that adds a zakat calculator via the `[zakat_calculator]` shortcode.

## Deployment

Hostinger Git deploy pulls the `main` branch into `public_html/wp-content/plugins/myzakattool`, so the plugin files live at the repo root.

After the first deploy, activate **My Zakat Tool** in WordPress → Plugins, then add `[zakat_calculator]` to any page.
